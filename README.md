🎵 Sistema Musical Web

📂 Estrutura do Projeto

O projeto é composto pelos seguintes arquivos:

login.html: Tela inicial de autenticação do usuário.

index.html: Menu principal de navegação do sistema.

cadastro_artista.html: Formulário de cadastro e listagem inicial de artistas.

cadastro_musica.html: Formulário para vinculação e cadastro de músicas com campos para vídeos (YouTube) e letras.

listagem_musicas.html: Interface da biblioteca musical com busca e filtros por artista e gênero.

styles.css: Folha de estilo única e centralizada para todo o sistema (utilizando CSS Grid, Flexbox, variáveis nativas e suporte a telas móveis).

🚀 Tecnologias Utilizadas

HTML5: Estruturação semântica das páginas, formulários com tipos específicos de entrada (url, file, password) e suporte a acessibilidade basilar.

CSS3:
Layout responsivo utilizando Flexbox e CSS Grid.

Uso de variáveis CSS (:root) para padronização de temas e cores.
